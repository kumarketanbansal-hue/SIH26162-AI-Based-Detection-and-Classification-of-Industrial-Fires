## 3. Backend API Endpoints Audit (`backend/main.py`)

All database connections in `backend/main.py` are created strictly through the centralized context manager `get_db_connection()`:

```python
@contextmanager
def get_db_connection():
    conn = psycopg2.connect(
        host=DB_HOST,
        port=DB_PORT,
        dbname=DB_NAME,
        user=DB_USER,
        password=DB_PASSWORD,
        sslmode=DB_SSLMODE,
    )
    try:
        yield conn
    finally:
        conn.close()
```
`DB_SSLMODE` is parsed from the environment via `os.getenv("DB_SSLMODE", "prefer")` (configured as `require` in production `.env`). Therefore, **100% of endpoints interacting with the database correctly pass and use `DB_SSLMODE`**.

### 4.2 VIIRS-Confidence-Based Parallel Dispatch
- **Status in Code**: **ACTIVE and FULLY IMPLEMENTED** in [`backend/main.py:666-735`](file:///c:/Users/kumar/SIH_2026/backend/main.py#L666-L735).
- **Behavior**:
  - When VIIRS `confidence` is `'h'` or `'high'`:
    1. Incident is inserted with `current_tier = 2`, `tier_0_sent_at = NOW()`, `tier_1_sent_at = NOW()`, `tier_2_sent_at = NOW()`, `alert_mode = 'parallel'`.
    2. Backend immediately dispatches three simultaneous emails to **Tier 0 (Local Operator)**, **Tier 1 (Safety Supervisor)**, and **Tier 2 (District Command)** in parallel.
    3. The background step-by-step escalation task is bypassed.
  - When VIIRS `confidence` is `'l'`, `'n'`, or nominal:
    1. Incident is inserted with `current_tier = 0`, `tier_0_sent_at = NOW()`, `alert_mode = 'sequential'`.
    2. Backend dispatches Tier 0 email immediately.
    3. Spawns background asyncio task `escalate_incident_task` to auto-escalate after 60s (to Tier 1) and another 60s (to Tier 2) unless acknowledged.
